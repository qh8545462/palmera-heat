Palmera Heat is an original 3D open-world crime game set in Palmera Bay, a
sun-soaked coastal city of palms, beaches and neon. You are Dani Marrero, a
wheelman working out of Ríos Auto Works: run story missions and an endless
boost list, steal and deliver cars, fight on foot, and outrun a five-star
police wanted system with chases, roadblocks and busts. Explore on foot or
by car across a five-by-five-block city with traffic, pedestrians, named
landmarks, a minimap, saves, and a synthesized soundtrack — all in the
browser, no network, no build step.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a browser
# (or just open game/index.html directly)
```
